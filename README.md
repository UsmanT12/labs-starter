# CSC 3001 Labs

This repo contains starter code for all lab assignments 
for CSC 3001.
To get started working on the labs, create a 
_fork_ of this repo under your own github account. 
You will submit your work by pushing each finished lab
to your own fork.

Since this is a private repo, your fork will remain
private. However, the instructors and graders for the
course will have access to your fork.
